## Data handling

Personal data touched: phone numbers, customer first name and support-ticket text, all already processed. No new data is collected. The template parameters now logged in `NotificationLog.templateParams` contain first name, ticket subject and reply text, which are the values already sent to Meta. Logged rows follow the existing `NotificationLog` retention (no change). Retention of that collection is reviewed in WA-14 (#976).

## Post-deploy controls

- Reversible via `git revert` of the REQ-115 merge. `WHATSAPP_API_VERSION=v18.0` restores the old Graph version without a deploy.
- The phone migration is run by the operator after UAT approval, as a dry-run first. Rollback is replaying the before values from the file it writes.
- Operator must set `WHATSAPP_API_VERSION=v23.0` (or unset it) in UAT and production, since an explicit `v18.0` overrides the new default.
