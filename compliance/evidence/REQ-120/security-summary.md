## Data handling

No new personal data. New orders no longer write guest name, email or phone. `ApiKey.userId` links a key to an existing customer record. Audit and order retention are unchanged.

## Post-deploy controls

- Revert the merge to roll back. `origin`, `channel` and `ApiKey.userId` are additive and ignored by old code; the removed customer tab pages return with the revert; no tab data was changed.
- Operator: run `npx tsx scripts/migrate-order-origin.ts` (dry run), then `--apply`, on UAT and then production; keep the output as evidence. The application is correct before and after, so the order relative to the deploy does not matter.
- Operator: before release, list open tabs created by customers (staff settle them from the dashboard) and identify integrations that post orders with customer keys (they need a customer key bound to a user, or a staff key).
